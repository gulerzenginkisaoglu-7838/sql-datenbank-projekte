# SQL & Datenbank Projekte

SQL-Übungen und Datenbank-Dateien im Rahmen der Umschulung zum Fachinformatiker Systemintegration (GFN).

## Inhalt

- **terra.sql** — MySQL-Dump mit drei zusammenhängenden Tabellen (kontinent, land, ort) inkl. Primär-/Fremdschlüssel-Beziehungen. Für MySQL/MariaDB bzw. phpMyAdmin gedacht (nicht direkt in SQLite lauffähig, da MySQL-spezifische Syntax wie ENGINE/CHARACTER SET verwendet wird).
- **MOCK_DATA.sql** — Beispieldatensatz (Länder, Währungen) zum Testen von INSERT-Anweisungen; SQLite-kompatibel.
- **Arbeitsblätter & Lernguides (.docx)** — Eigene Lösungen und Zusammenfassungen zu Aggregatfunktionen, SQL-Grundlagen und praktischen Übungen (Fahrt, Grandhotel, u.a.)
